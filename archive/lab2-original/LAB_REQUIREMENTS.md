# Соответствие условиям ООП, 2 семестр

Источник: предоставленный PDF «ООП Лабы 2 семестр-Паблик (2).pdf», страницы 1–4.

| Условие | Реализация / артефакт |
|---|---|
| Клиент-серверное приложение, реальная задача | React + Spring Boot; поиск собеседника по интересам, общение после взаимного like |
| Не меньше 10 сущностей | 12 JPA-сущностей и таблиц; см. ERD |
| Не меньше 7 предметных сущностей | UserAccount (участник), Interest (интерес), Preference (предпочтение), Reaction (симпатия/пропуск), PairMatch (взаимное знакомство), ChatMessage (сообщение), Notice (уведомление) |
| Остальные сущности | ProfileProperty (характеристика участника), UserInterest (выбранный интерес), SessionToken (сессия), PrivateContext (личный рассказ и эмбеддинг), ProfilePhoto (снимок галереи) |
