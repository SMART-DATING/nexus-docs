# Первое знакомство

## Путь пользователя

Первый диалог запрашивает отдельный уникальный логин, email, пароль и подтверждение пароля. Клиент показывает, совпадают ли пароли, и блокирует отправку при несовпадении. Сервер также проверяет подтверждение и занятость логина. Вход допускает логин или email; прежние аккаунты продолжают входить по email.

После регистрации пользователь выбирает от нуля до десяти публичных тем. Каталог включает книги, музыку, психологию и другие широкие интересы. Следующий шаг — имя, дата рождения, город, свой пол и кого хочется встретить; дата рождения скрыта по умолчанию. После рассказа открывается загрузка фото, если ещё нет ни одного кадра. Подпись необязательна.

Затем приложение задаёт три вопроса: до двух по выбранным конкретным темам, оставшиеся — общие. Порядок детерминирован, генеративная модель не используется. Для книг — что недавно зацепило, для музыки — что звучит на повторе, для психологии — что интересно понимать в людях. Без выбора или при общей теме «Кофе» вопросы касаются хорошего дня, увлечений и близкого общения.

Любой вопрос можно пропустить; назад возвращается сохранённый в памяти черновик. Один ответ ограничен 1800 символами. После третьего вопроса показывается объединённый личный рассказ: только непустые ответы с названиями тем, без текстов вопросов. Пользователь редактирует и явно сохраняет его (20–6000 символов). Пустой рассказ не сохраняется.

Шаг можно отложить. Он не появляется повторно в той же сессии вкладки, а в профиле остаётся кнопка повторного интервью. Клиент открывает знакомства после заполнения основных данных, сохранения хотя бы одного рассказа и добавления одного фото. Собственно API рейтинга сохраняет совместимость: без фото возвращает анкеты с закрытой галереей. В интерфейсе видны все незавершённые шаги, а основная кнопка ведёт непосредственно к следующему. Черновики не переживают закрытие или обновление страницы; сохранённые данные находятся на сервере. Пока история не сохранена, API запросов с её содержимым нет.

## Голос

Некс сопровождает выбор интересов, базовые сведения и вопросы. В разделе «Для подбора» сначала выбираются интересы, затем открываются три коротких вопроса по выбранным темам. Если интересы уже выбраны при регистрации, основные данные заполнены, а рассказа ещё нет, сразу открываются вопросы с этими темами. Можно перейти к свободному рассказу; название необязательно. Смена тем сохраняет ответы по идентификаторам вопросов, свободный черновик остаётся в памяти. Сохранённые истории можно раскрыть и дополнить. Это подготовленные тематические вопросы, а не генеративный чат. Некс не отправляет ответы автоматически и не требует включать микрофон.

Сначала открывается пояснение об обработке звука браузером. Только отдельная кнопка запускает распознавание и запрос разрешения на микрофон. Повторные промежуточные результаты заменяют друг друга, а не дублируют текст. При остановке учитывается последний результат, при смене вопроса распознавание отменяется.

Nexus получает итоговый текст при сохранении, аудиозапись не принимает. Браузер может отправлять звук своему сервису — это отличается от локального NLP-подбора на сервере. Отказ в разрешении, отсутствие речи, ошибка сети или неподдерживаемый API оставляют текстовую альтернативу. Доступность зависит от браузера, разрешений, HTTPS / localhost и его сервиса распознавания. Реального офлайн-распознавания на стороне Nexus нет.

Основание: [SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition), [Web Speech API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API/Using_the_Web_Speech_API).

## Интерфейс

Тёмный фон, синие и фиолетовые акценты, крупные заголовки, мягкие поверхности и короткие переходы. Вопрос появляется с лёгким движением, поле выделяется при фокусе, запись сопровождается индикатором. `prefers-reduced-motion` отключает движение.

На экране знакомств карточка и две подписанные кнопки образуют основной блок; его высота зависит от viewport. Панель действий остаётся рядом с карточкой. На телефоне навигация закреплена снизу, второстепенные боковые панели убраны. Свайпы не заменяют кнопки; клавиатурные действия доступны при фокусе карточки. Голос не заменяет текст.

Подтверждение загрузки, замены и удаления фото открывается отдельным диалогом с выбранным кадром и соседними действиями. До подтверждения файл остаётся локальным. Ошибка остаётся в диалоге для повтора, успешная загрузка предлагает перейти к знакомствам. При незавершённой подготовке подсказки остаются в профиле и пустом подборе.
