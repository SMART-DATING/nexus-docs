# Бизнес-требования

## Проблема и аудитория
Совершеннолетнему пользователю трудно найти собеседника с общими интересами среди случайных анкет. Nexus должен сократить усилия на поиск и дать повод для содержательного первого разговора.

## Цели продукта
| ID | Ожидаемый результат для пользователя | Как оценить на пилоте |
|---|---|---|
| BR-01 | Быстрее находить людей с общими интересами | Время от заполнения профиля до первой релевантной симпатии; сравнить с неранжированной выдачей |
| BR-02 | Начинать общение при взаимной заинтересованности | Доля совпадений, где состоялся обмен сообщениями; ни одного чата без взаимного согласия |
| BR-03 | Управлять раскрытием информации о себе | Пользователь понимает видимость полей; скрытые значения не выдаются другим участникам |
| BR-04 | Понимать основание рекомендации | Пользователь может назвать общие интересы с рекомендованным человеком |
| BR-05 | Пройти путь знакомства без технической помощи | Участники пилота выполняют сценарий «профиль → симпатия → совпадение → сообщение» |

Это цели и способы оценки, а не заявленные результаты исследования. Численные целевые значения определяются после пилота; аналитика конверсии в прототипе не реализована.

## Учебный результат
Продемонстрировать клиент-серверное приложение, объектную модель, хранение данных, бизнес-правила, разделение ответственности и согласованную документацию. Приёмочный критерий — воспроизводимый сценарий на двух аккаунтах с проверкой отказа третьему участнику.

## Границы
В локальном прототипе не оцениваются коммерческая эффективность, качество ML, модерация и масштабирование. Регистрация, API и BCrypt — способы реализации целей, а не самостоятельные бизнес-цели.
