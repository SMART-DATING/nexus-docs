# Пользовательские сценарии

1. Участник регистрируется, по желанию выбирает темы, указывает имя, дату рождения и город. Отвечает на три коротких вопроса текстом или голосом, пропускает ненужные, редактирует рассказ и подтверждает сохранение. Весь этап можно отложить.
2. В личном редакторе пишет об интересах, ценностях или идеальном дне; сохраняет рассказ. Он может дополнить его или добавить новый. Другие участники не читают эти тексты.
3. Загружает до шести фото с предварительным просмотром. Переставляет главное, заменяет или удаляет. Число своих фото определяет число открытых чужих.
4. Получает подборку по косинусному сходству личных текстов. Видит только доступные фотографии, публичные поля и темы. Score подписан как сходство рассказов, не вероятность отношений.
5. Свайпом влево пропускает, вправо ставит Like; доступны кнопки и клавиши. После новых кандидатов пропущенные возвращаются по кругу, лайкнутые не повторяются.
6. Второй участник отвечает Like — открывается match. Два пользователя обмениваются сообщениями, получают уведомления. Посторонний получает 403.
7. Пользователь уходит из чата в профиль и обновляет страницу — остаётся в профиле. Возврат через историю браузера восстанавливает корректный экран.
8. При удалении своего второго фото вторые чужие фото закрываются даже по ранее полученной ссылке. При выходе media-ticket отзываются.

Негативные сценарии: неправильный пароль, повторный email/Like, незавершённый профиль/нет рассказа, чужое редактирование рассказа или фото, седьмой снимок, повреждённый файл, просроченная сессия/ссылка, недоступный API или модель. Интерфейс показывает причину и позволяет исправить ввод.
