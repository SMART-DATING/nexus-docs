# Функциональные требования

| ID | Поведение | Приёмка |
|---|---|---|
| FR-AUTH-01 | Регистрация, вход, выход, независимые сессии вкладок на 24 часа | Уникальный email; BCrypt; неверный вход 401; отозванный токен не принимается |
| FR-ONBOARD-01 | Темы → основные данные → три вопроса → редактирование → сохранение | Темы необязательны; вопросы можно пропустить; черновик не отправляется до подтверждения |
| FR-VOICE-01 | Голосовой ввод при поддержке браузера | Отдельное подтверждение; ошибки и отсутствие поддержки оставляют текстовый ввод; аудио в Nexus не хранится |
| FR-PROFILE-01 | Четыре свойства: имя, подпись bio, дата рождения, город | Автор видит все свои поля; чужие скрытые поля не передаются |
| FR-CONTEXT-01 | Отдельные личные рассказы для подбора | До 12, каждый 20–6000 символов, название 1–60; создание, дополнение, удаление только владельцем |
| FR-CONTEXT-02 | Контекст закрыт от других участников | Тексты, названия, векторы отсутствуют в публичном профиле, подборке и match |
| FR-REC-01 | Локальные эмбеддинги RuBERT-tiny2 и косинусное сходство | Смысловые парафразы выше посторонних тем; изменение рассказа пересчитывает вектор |
| FR-REC-02 | Круговой просмотр Skip | Сначала новые подходящие анкеты, затем свои Skip; Like и чаты сохраняются; GET не меняет историю |
| FR-PHOTO-01 | Галерея 0–6 снимков, замена, удаление, перестановка | JPEG/PNG ≤5 МБ, ≤25 MP; JPEG после декодирования до 1200 px; седьмой снимок 409 |
| FR-PHOTO-02 | Взаимное раскрытие галереи | Автор видит все свои фото; другой видит первые min(его фото, фото автора); без своих фото не видит чужих |
| FR-PHOTO-03 | Ограничение защищено сервером | Скрытые ID/URL не передаются; выдача изображения проверяет актуальную квоту и порядок |
| FR-INTEREST-01 | 0–10 публичных тем | Только справочник; темы нужны для общения, не заменяют смысловой подбор |
| FR-PREF-01 | Возрастной диапазон 18–100 | min ≤ max; применяется к выдаче |
| FR-REACTION-01 | Like / Skip кнопками, свайпом, клавиатурой | Короткий и вертикальный жест не вызывает реакцию; при ошибке карточка остаётся |
| FR-MATCH-01 | Взаимные Like создают один match | Включая одновременные запросы; самореакция 400, повтор 409 |
| FR-CHAT-01 | Чат только участникам match | Текст 1–5000; отправка 201; чужой match 403 |
| FR-NOTICE-01 | Уведомления о match и сообщении | Переход к чату, отметка прочтения только владельцем |
| FR-UI-01 | Русский интерфейс в тёмной сине-фиолетовой палитре | Галерея, редактор рассказов, свайпы, ошибки, пустые состояния, маршруты |
| FR-DEMO-01 | 14 вымышленных анкет | По 6 иллюстраций и личный рассказ; перезапуск не затирает изменения |

Базовый профиль требует всех четырёх свойств; bio может быть пустой, теги необязательны. Для подбора дополнительно нужен личный рассказ. Кандидат без рассказов не включается. Фото не обязательны для подбора или чата. Возраст 18–100 проверяется по дате, удостоверения личности не проверяются.

Рассказ сохраняется только после подтверждения, отправляется локальному серверу и кодируется локальной моделью. Локальная модель подбора не обращается к внешним сервисам. При голосовом вводе браузер может передавать звук своему сервису распознавания; пользователь видит пояснение до запуска микрофона. Удалённый рассказ больше не участвует в векторе. Несколько рассказов имеют равный вес после нормализации; длинный текст обрабатывается блоками без отбрасывания хвоста.

Не реализованы: CV/анализ внешности, collaborative filtering, модерация, жалобы/блокировки, восстановление пароля, удаление аккаунта, геолокация, push, WebSocket. Результат сходства — не вероятность успешных отношений.


## Публичный вход и управление данными

До входа пользователь видит информацию о Nexus и отдельные действия входа/регистрации. Фотографии перелистываются в карточке либо в диалоге просмотра с сохранением серверной квоты. Аватар открывает меню аккаунта; собственный предпросмотр исключает скрытые свойства и личные рассказы.

Пользователь может приостановить показ анкеты новым людям и вернуть её без потери истории. Проверка видимости выполняется сервером для выдачи, прямого просмотра, реакций и фотографии по выданной ссылке. Существующие чаты сохраняются. Собственная выгрузка включает данные, перечисленные в API-контракте, и не содержит секретов доступа или полученных сообщений других участников.

Для локальной проверки показывается описание потоков данных, а не фиктивное согласие или политика несуществующего оператора. Условия публичного запуска перечислены в [privacy/data-handling.md](../privacy/data-handling.md).
