# Функциональные требования прототипа

| ID | Реализованное поведение | Критерий приёмки |
|---|---|---|
| FR-AUTH-01 | Регистрация по уникальному email и паролю; сразу создаётся сессия | 201, токен и пользователь; повторный email — 409 |
| FR-AUTH-02 | Вход/выход; сессия действует 24 часа | Неверные данные — 401; после выхода токен не принимается |
| FR-PROFILE-01 | Имя, bio, дата рождения, город хранятся в `profile_properties` | По одному свойству каждого вида; имя публично; дата рождения по умолчанию скрыта |
| FR-PROFILE-02 | Владелец выбирает видимость bio/даты/города | Непубличные свойства отсутствуют в публичных ответах |
| FR-INTEREST-01 | Выбор 1–10 интересов из справочника | Неизвестные значения отклоняются |
| FR-PREF-01 | Возрастной диапазон 18–100 лет | min ≤ max; фильтр применяется к кандидатам |
| FR-REC-01 | Ранжирование по коэффициенту Жаккара интересов | Исключены сам пользователь, неполные профили, уже обработанные и не подходящие по возрасту |
| FR-REACTION-01 | Like и Skip сохраняются | Повторная реакция — 409; самореакция — 400 |
| FR-MATCH-01 | Match появляется только при двух Like | Одна запись для неупорядоченной пары, в том числе при одновременных запросах |
| FR-CHAT-01 | Участники могут читать и отправлять сообщения | Чужой match — 403; пустой текст / >5000 символов — 400 |
| FR-NOTICE-01 | Уведомления о match и сообщении; отметка прочтения | Чужое уведомление нельзя изменить |
| FR-REC-02 | Круговой просмотр пропущенных | POST /recommendations/next сначала выдаёт непросмотренные подходящие анкеты, затем возвращает собственные Skip; Like, чужая история и чаты сохраняются |
| FR-PHOTO-01 | Загрузка, замена и удаление одного публичного фото | JPEG/PNG до 5 МБ; превью перед сохранением, серверная проверка и уменьшение до 1200 px; фото сохраняется в БД |
| FR-SWIPE-01 | Свайпы мышью/пальцем и кнопки Skip/Like | Влево — Skip, вправо — Like; короткий/вертикальный жест не вызывает реакцию; при ошибке карточка остаётся |
| FR-UI-02 | Раздел страницы сохраняется при обновлении и переходах Назад/Вперёд | Уход из /match/{id} меняет URL; после обновления открывается выбранный раздел |
| FR-DEMO-01 | 14 вымышленных профилей с локальными SVG-аватарами | Повторный запуск добавляет отсутствующие демоанкеты и аватары, не перезаписывает заполненные профили |
| FR-UI-01 | Русский интерфейс с формами, ошибками и пустыми состояниями | Основные разделы доступны на широком и узком экране |

Профиль считается заполненным, если сохранены все четыре свойства и минимум один интерес. Bio может быть пустым. Возраст рассчитывается по дате, сервер проверяет 18–100 лет; подтверждения личности/возраста по документам нет.

Имя: 1–60 символов после проверки на пустоту; город: 1–80; bio: до 1000. Пароль: 8–72 символа и не более 72 байт UTF-8 (ограничение BCrypt). Email нормализуется к нижнему регистру.

Обновление профиля и интересов атомарно через PUT /profiles/me. Справочник хранится в таблице interests, исходные названия инициализируются классом Interests. Выбранные интересы представлены UserInterest, возрастные настройки — Preference. Skip исключает анкету до окончания непросмотренных подходящих анкет. POST /recommendations/next автоматически начинает новый круг собственных Skip; Like, Match и сообщения сохраняются. Непубличные свойства не показываются, однако дата рождения используется для фильтрации на сервере. Интересы публичны и участвуют в расчёте.

Не реализованы: галерея нескольких фото, почтовое подтверждение/восстановление пароля, жалобы/блокировки, удаление аккаунта, ML/embeddings, геолокация, push, WebSocket, отметки прочтения отдельных сообщений. Это задачи развития, а не скрытые части MVP.
