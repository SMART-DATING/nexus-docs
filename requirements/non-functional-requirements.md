# Нефункциональные требования и ограничения

- Java 21, React/TypeScript, PostgreSQL 16 либо локальная файловая H2. Готовый комплект запускается одним START.cmd; Docker требует Linux containers и сети при первой сборке.
- NLP работает локально на CPU через ONNX Runtime. Веса ~116 МБ, JAR с runtime ~154 МБ. Во время обработки тексты не уходят во внешний API. Сборка и загрузка модели требуют сети; фиксированная ревизия и SHA-256 описаны в MODEL.md.
- Bearer-сессии 24 часа, хеш токена в БД; пароли BCrypt. Личные тексты доступны автору через API, изображения только по текущей квоте и временной ссылке. База хранит тексты и фото открыто для её администратора; это не end-to-end encryption.
- JPEG/PNG ≤5 МБ и 25 MP; сервер декодирует, убирает метаданные и сохраняет JPEG ≤1200 px. Не доверяет MIME и имени файла. Галерея максимум 6, рассказов максимум 12, длина 20–6000.
- Подбор детерминирован при неизменных данных: cosine ↓, userId ↑. Score не является вероятностью отношений или психологической оценкой.
- Ошибки API имеют status/message; клиент показывает ошибки, пустые состояния и сохраняет карточку при неуспешной реакции. Чат polling 2s, уведомления 7s; HTTP timeout 15s.
- Данные переживают перезапуск (файл H2 / Docker volume). Не удалять volume для обычной остановки. Одновременные Like/Skip и лимиты галереи защищаются транзакциями/блокировками.
- Поддержка узких экранов, доступные подписи кнопок, клавиатурные действия и prefers-reduced-motion. Реальные пользовательские и нагрузочные исследования пока не проведены.
- Для Linux с 8 ГБ предусмотрен Compose: nginx, JRE heap 512 МБ плюс native ONNX, PostgreSQL. Производительность на целевом устройстве требует измерения; не заявляется SLA.
- Учебный прототип без публичной эксплуатации: нет модерации, rate limit, подтверждения email, удаления аккаунта, версионированных миграций и распределённого хранилища media-ticket.

- Голосовое распознавание зависит от браузера и его сервиса. Перед запуском показано пояснение; ошибки разрешения и сети не блокируют текст. Анимации учитывают prefers-reduced-motion.
