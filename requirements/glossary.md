# Термины предметной области

| Термин | Значение в Nexus |
| --- | --- |
| Участник | Владелец зарегистрированного аккаунта. Гость видит публичную главную, но не подборку людей |
| Аккаунт | Учётная запись с email, логином, хешем пароля и настройками участия |
| Анкета / профиль | Представление основных сведений, публичных интересов и разрешённых фотографий участника. Отдельной таблицы `profiles` нет |
| Публичное поле | Поле анкеты, отмеченное владельцем как видимое другим авторизованным участникам; это не общедоступная страница без входа |
| Интерес / тема | Выбранное значение справочника: музыка, книги и т. п. Показывается в анкете и помогает выбрать вопросы |
| Личный рассказ / контекст | Закрытый текст владельца для смыслового подбора. Не является публичной подписью `bio` |
| Некс | Персонаж и интерфейсный помощник, задающий подготовленные вопросы. Генеративная модель диалога не используется |
| Эмбеддинг | Числовое представление текста, полученное локальной моделью |
| Сходство / compatibilityScore | Косинусное сходство векторов рассказов. Не оценка личности и не вероятность отношений |
| Подборка | Очередь подходящих по правилам анкет: свой город первым, затем другие; внутри групп — по сходству |
| Like / симпатия | Положительная реакция на другого участника |
| Skip / пропуск | Реакция, временно убирающая анкету из текущего круга просмотра |
| Круг просмотра | Проход по подходящим анкетам. После исчерпания непросмотренных могут вернуться собственные Skip; Like сохраняются |
| Match / взаимность | Результат двух встречных Like; даёт двум участникам доступ к чату |
| Чат | Переписка участников одного match; отдельной таблицы `chats` нет |
| Квота фотографий | Число своих фото, определяющее верхнюю границу числа видимых чужих. Свои снимки доступны владельцу полностью |
| Media-ticket | Временное разрешение в URL конкретного фото. Не сессионный токен и не постоянная публичная ссылка |
| Пауза анкеты | Скрытие от новых знакомств с сохранением существующих чатов |
| Блокировка | Собственное ограничение контакта с человеком. Наличие блокировки любой стороны закрывает взаимодействие обеим |
| Очистка / удаление чата | Личные настройки видимости истории и списка чатов; не физическое удаление общей переписки |
| Демо | Изолированная проверка приложения на тестовых аккаунтах; не производственная база реальных пользователей |
