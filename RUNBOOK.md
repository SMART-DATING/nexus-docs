# Запуск и демонстрация Nexus

## Готовый комплект
1. Остановить прежнее окно backend через Ctrl+C.
2. Открыть SMART-DATING/START.cmd двойным щелчком. Нужна Java 21+, установленная Corretto определяется автоматически.
3. Дождаться Started NexusApplication и открыть http://127.0.0.1:8080/.
4. Войти demo@nexus.local / NexusDemo2026!. Второй аккаунт demo1@nexus.local, пароль тот же.

Оставить окно открытым. В одном JAR уже frontend и backend. Docker, Maven и npm для комплекта не нужны. Рядом обязательно сохранить models/rubert-tiny2/model.onnx и vocab.txt: модель работает локально, без API-ключа и оплаты. Файл БД создаётся в data; обновление комплекта не требует удаления data. Нельзя одновременно запускать два сервера на одном файле H2. Linux: sh START.sh из каталога комплекта.

14 демоанкет (demo и demo1…demo13) вымышлены, содержат шесть локальных иллюстраций и личные рассказы. Повторный запуск дополняет недостающее, не перезаписывает заполненные рассказы, профиль или переписки. У обычного существующего аккаунта для нового подбора нужно добавить личный рассказ.

## Из исходников без Docker
Клонировать nexus-backend, nexus-frontend, nexus-docs рядом, все из ветки main. Нужны JDK 21 и Node.js 22.12+. В backend:
```powershell
pwsh -File scripts/download-model.ps1
.\mvnw.cmd clean package
java -jar target/nexus-backend-0.0.1-SNAPSHOT.jar --spring.profiles.active=local --nexus.demo=true
```
Linux: sh scripts/download-model.sh, затем ./mvnw вместо .\mvnw.cmd. Java запускать из backend; другой каталог модели задаётся NEXUS_MODEL_DIR. Скрипт скачивает фиксированные веса и словарь с SHA-256, не исполняет сторонний код. Детали в architecture/MODEL.md.

В другом окне, из frontend: npm ci, npm run dev. Открыть http://127.0.0.1:5173/. Vite проксирует /api на 8080, порт фиксирован. Health: /api/v1/health, ожидается status:ok. Для единого JAR использовать build-demo.ps1/sh в docs: скрипт скачивает модель, проверяет backend и встраивает React. При переносе JAR переносить и backend/models, либо задать NEXUS_MODEL_DIR.

## Docker
Требуется Docker Engine/Desktop с Linux containers. Из frontend: docker compose up --build --wait. Открыть http://127.0.0.1:8088/. Compose запускает PostgreSQL, backend и nginx. Веса загружаются при сборке, в работающем приложении интернет для NLP не требуется.

Из backend: docker compose up --build --wait — только PostgreSQL/API на 8080; NEXUS_DEMO=true включает демоданные. Альтернатива без PostgreSQL: docker compose -f compose.h2.yaml up --build --wait, демо включено, H2 в volume.

Остановка: соответствующий docker compose down. Не добавлять -v при обычной остановке: это удалит базу. Старый mandatory interests.category поддержан без потери данных. Docker runtime использует glibc JRE для ONNX.

## Демонстрация концепции
1. Два аккаунта в отдельных вкладках: сессии независимы. Заполнить основные поля, добавить личные рассказы близкого смысла разными словами.
2. Без своих фото чужие скрыты. Загрузить одно — видно первое, два — первые два; максимум шесть. Проверить порядок, замену, удаление и сохранение после обновления.
3. В знакомствах увидеть «сходства рассказов». Подробные тексты собеседника закрыты, публичные темы показываются отдельно. Дополнить рассказ или добавить ещё один — подбор обновится.
4. Свайп влево Skip, вправо Like; есть кнопки и стрелки клавиатуры. После новых анкет возвращаются Skip, Like не повторяются.
5. Встречные Like открывают match. Отправить сообщения в обе стороны, проверить уведомления. Перейти из чата в профиль и обновить страницу — остаётся профиль.

Автоматических ответов от демоанкет нет: второй пользователь действует в другой вкладке. Старый match остаётся в «Совпадениях».

## Если не запускается
- 8080 занят: остановить прежний backend. Vite 5173 нужен только в режиме разработки.
- /api/v1/health не отвечает: смотреть окно Java / docker compose logs backend.
- На / у API без встроенного frontend возможен 404; открыть 5173 или собрать единый JAR.
- H2 locked: два процесса используют один файл; закрыть лишний, не удалять данные.
- Модель не установлена: скачать скриптом и перезапустить; проверить NEXUS_MODEL_DIR. Нет подмены NLP тегами.
- 401: войти снова. 409 при подборе: заполнить основные поля и добавить личный рассказ.
- Фото не открывается после долгого ожидания: обновить подборку; временный media-ticket действует 15 минут. После удаления своих фото квота уменьшается сразу.
- Выдача пуста: расширить возраст; если все подходящие лайкнуты, повторять их нельзя. Без рассказов кандидаты не участвуют.

## Первое знакомство
После регистрации выбрать темы или продолжить без них, заполнить имя / дату / город, ответить на вопросы. На последнем шаге проверить личный текст и сохранить. Любой вопрос и весь шаг можно пропустить; продолжение находится в профиле. Для голоса нажать «Голосом», прочитать пояснение и отдельно включить микрофон. Если распознавание не поддерживается, продолжить текстом или диктовкой клавиатуры телефона.
