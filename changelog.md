# Изменения прототипа — 7 октября 2026

| Исходный материал | Решение | Причина |
|---|---|---|
| Profile с фиксированными колонками | ProfileProperty (name, value, visible, userId) | Учесть предложенную преподавателем модель свойств и приватность |
| Бизнес-требования как перечень функций | Цели пользователя и критерии оценки | Отделить «зачем» от «что реализует система» |
| match/{matchid} | Страница /match/{id}, API /matches/{id} и alias /match/{id} | Явный ресурс совпадения и проверка участника |
| JWT | Отзываемый непрозрачный Bearer | Простой рабочий logout без секретного ключа и refresh-протокола |
| Отдельные Interest/Preference | Interest, UserInterest и Preference в базе; исходный справочник в ru.nexus.Interests | Сохранить предметную модель и выполнить требование лабораторной о 10 сущностях |
| ML / embeddings | Прозрачная формула пересечения интересов | Не заявлять ML без модели и данных |
| Фото | Декоративные инициалы | Отложить хранение и модерацию загрузок |
| PostgreSQL обязателен при старте | PostgreSQL в Compose, H2 для локального демо | Можно показать приложение без Docker |
| WebSocket/real time | Опрос чата и уведомлений | Достаточно для демонстрации двух клиентов |
| Пример регистрации без авто-входа | Регистрация сразу создаёт сессию | Сократить путь к заполнению профиля |

Архив первоначальных Markdown сохранён. Роли команды не менялись. Снимок замечаний преподавателя трактуется как предложение по модели, а решение о применении принято в рамках разрешения автора запроса менять требования.

# Исправление совместимости сохранённой базы

Interest сохраняет обязательное поле category из ранней схемы PostgreSQL. Новые записи получают «Общее», категории существующих записей сохраняются. Добавлены проверка запуска на старой таблице и такой же сценарий в Docker CI; сброс базы не требуется.
