# Изменения документации

## 15 октября 2026

Повторно проверены README всех четырёх репозиториев, требования, API и схемы по исходникам. Уточнены совместимые версии Node.js по package-lock, PowerShell 7 и инструменты загрузки модели для Linux. Правила подтверждения фото, последовательной загрузки нескольких файлов и состав публичных DTO согласованы с кодом. Матрица теперь связывает все функциональные и нефункциональные требования с проверками. Бизнес-показатели уточнены как результаты пользовательского исследования.

## 14 октября 2026

Документация приведена к текущему веб-приложению. Бизнес-цели отделены от функций и технических решений; добавлены единые термины, критерии приёмки и связь целей со сценариями/проверками. API описан по контроллеру, DTO и сервисам без накопленных противоречащих дополнений.

ERD отражает 14 текущих сущностей и различает физические FK от логических ссылок. Добавлены словарь данных, архитектурная схема, UML, последовательности основных операций и состояния взаимодействия. Инструкции запуска различают H2, PostgreSQL/Compose, Vite и единый JAR.

README компонентов и страница организации согласованы с документацией. Устаревшие копии и изображения убраны из текущей редакции; прежние версии сохраняются в истории Git. Пользовательское поведение программы этим изменением не меняется.

Текущий состав функций — в [STATUS](STATUS.md), открытые задачи — в [roadmap](roadmap.md). История разработки исходников находится в коммитах и Pull Request соответствующих репозиториев.
