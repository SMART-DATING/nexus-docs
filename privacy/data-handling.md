# Данные и правила доступа

Документ описывает техническую обработку данных текущим приложением. Он не подменяет условия использования и политику конкретного оператора постоянного публичного сервиса.

## Что хранится и кто получает доступ

| Данные | Хранение | Доступ через приложение |
| --- | --- | --- |
| Email и логин | `users` | Только собственный аккаунт; в чужую анкету не входят |
| Пароль | BCrypt-хеш в `users` | Не выдаётся API и не входит в выгрузку |
| Сессия | SHA-256 случайного токена в `sessions`, срок 24 ч | Исходный токен выдаётся при входе и хранится клиентом в sessionStorage |
| Имя, bio, дата рождения, город | `profile_properties`, с признаком visible | Владелец видит все; остальные — только разрешённые. Имя обязательно публичное |
| Пол и предпочтения | `users`, `preferences` | Только владельцу; используются для правил подбора |
| Интересы | `user_interests` и справочник | Публичные в доступной авторизованному участнику анкете |
| Истории, названия и векторы | `private_contexts` | Текст/название только автору; векторы не возвращаются клиентам |
| Фотографии | JPEG в `profile_photos`; старые avatar-поля могут сохраняться | Владельцу — все, другому — в пределах квоты и текущего доступа |
| Реакции и match | `reactions`, `matches` | Реакции влияют на свою очередь; match открывает данные его участникам |
| Сообщения | `messages` | Только участникам незаблокированного match; личная очистка дополнительно ограничивает историю |
| Блокировки и настройки чатов | `user_blocks`, `chat_preferences` | Каждый управляет своими настройками; чужие списки не выдаются |
| Уведомления | `notifications` | Получателю; недоступные/лично скрытые чаты исключаются |
| Активность | `users.last_active_at` | Время собеседника в доступном match, не всем пользователям |

Закрытость истории означает изоляцию между участниками через API. Текст и фото не зашифрованы от администратора БД. Временная ссылка фото — разрешение на доступ, а не защита от сохранения/пересылки уже доступного изображения.

## Потоки обработки

Личный текст отправляется на backend после явного сохранения. Модель запускается в том же процессе локально; облачного NLP API нет. Для установки веса скачиваются из фиксированной ревизии, но пользовательские тексты при этом никуда не передаются.

Голос распознаёт браузер при отдельном действии и разрешении. Его сервис может передавать звук вне устройства. Nexus принимает итоговый редактируемый текст; API загрузки аудио для этого сценария нет. Отказ от микрофона не препятствует печати.

Фотографии декодируются, ограничиваются по размеру и сохраняются как JPEG без исходных метаданных. Исходный файл в текущем пути загрузки не сохраняется отдельно.

В браузере sessionStorage хранит токен и отложенное первое знакомство; черновики редакторов находятся в памяти компонентов. Локальное напоминание о коротком рассказе использует localStorage с ключом аккаунта и недельным интервалом. Это не серверное уведомление и не внешняя аналитика.

## Видимость и прекращение контакта

| Действие | Новые знакомства | Существующий match | Хранение |
| --- | --- | --- | --- |
| Скрыть поле | Значение отсутствует в чужом профиле | Тоже скрыто в профиле собеседника | Значение остаётся у владельца |
| Удалить своё фото | Снижается квота; лишние чужие кадры закрываются | То же ограничение фото | Строка фото удаляется; прежние legacy avatar-поля могут оставаться |
| Поставить анкету на паузу | Анкета не выдаётся, новые реакции от неё запрещены | Сохраняет доступ к профилю/чату | Данные и реакции не удаляются |
| Заблокировать | Взаимный доступ закрыт | Чат и медиа закрыты обеим | История и match сохраняются |
| Очистить чат | Не меняет подбор | Старые сообщения скрыты только инициатору | Строки сообщений остаются |
| Удалить чат из списка | Не меняет подбор | Скрыт только инициатору; новое сообщение возвращает | Match и сообщения остаются |
| Выйти | Текущая сессия отозвана | Для дальнейшего доступа нужен вход | Аккаунт и содержимое не удаляются |

Разблокировка снимает только собственную запись. Если другая сторона продолжает блокировать, доступ не восстанавливается. Квота и видимость перепроверяются сервером при обращении к фото, включая уже выданные ссылки.

## Выгрузка

Собственная выгрузка JSON включает аккаунт без секретов, свои фото в base64, личные рассказы, свои реакции, отправленные сообщения, блокировки и настройки чатов. Не включает хеш пароля, токены, исходящие фото-ticket, чужие рассказы и полученные сообщения. Это просмотр собственных данных, не полная резервная копия и не удаление.

## Известные ограничения

Нет удаления аккаунта, восстановления пароля, подтверждения email, модерации и обработки жалоб. Нет автоматического срока хранения аккаунтов/переписки и процесса удаления связанных данных; истёкшие сессии отклоняются, но обязательная автоматическая очистка всех старых записей не заявляется. Пауза не является полным удалением.

Перед постоянным публичным размещением нужно определить оператора, правила/сроки обработки, контакты для обращений, удаление и восстановление доступа; настроить HTTPS, защиту запросов, резервное копирование, мониторинг и управляемые миграции. Эти задачи отражены в [roadmap](../roadmap.md), а не выданы за работающие механизмы.

Проверки доступа и состав выгрузки — [API](../architecture/api-contracts.md) и [TESTING](../TESTING.md).
