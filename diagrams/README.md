## Как читать и обновлять

Для мелких подписей откройте SVG отдельно и увеличьте масштаб. ERD показывает логические связи; наличие линии само по себе не означает физический внешний ключ. Полные поля и ограничения описаны в [словаре данных](../architecture/data-dictionary.md).

Mermaid-блок на соответствующей странице — источник схемы. После правки экспортируйте этот же блок в SVG/PNG и обновите изображения в assets; текст и экспорт не должны расходиться. Текущие экспорты проверены Mermaid CLI 11.12.0 с классическим оформлением и шрифтом Arial. Блоки не требуют экспериментальных типов диаграмм.

Пример экспорта после сохранения блока в временный diagram.mmd:

```sh
npx --yes --package @mermaid-js/mermaid-cli@11.12.0 mmdc -i diagram.mmd -o diagram.svg -c diagrams/mermaid-theme.json -b '#0f1729'
```

Для PNG замените расширение выходного файла. CLI требует совместимый headless-браузер; экспорт из Mermaid-редактора также допустим. Прежде чем обновлять схему, сверяйте сущности/методы/переходы с кодом, а не только с прежней картинкой.
