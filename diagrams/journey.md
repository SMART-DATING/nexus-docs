# Путь пользователя

Схема отражает основной путь интерфейса и возможность отложить подготовку. Готовность в UI требует основных сведений, сохранённой истории и хотя бы одного фото. Checklist направляет к конкретному недостающему шагу; сохранённые данные не удаляются при пропуске дальнейшего заполнения.

```mermaid
flowchart TD
  accTitle: Пользовательский путь Nexus
  accDescr: Вход и регистрация ведут к подготовке анкеты. Подготовку можно отложить, недостающие шаги остаются доступны. После взаимных симпатий открывается чат.
  HOME["Публичная главная"] --> LOGIN["Вход"]
  LOGIN -->|"новый участник"| REG["Регистрация<br/>email, логин, пароль × 2"]
  LOGIN -->|"вход выполнен"| READY{"Данные, история<br/>и фото готовы?"}
  REG --> TOPICS["Публичные интересы<br/>0–10 тем"]
  TOPICS --> BASIC["Имя, дата, город<br/>пол и предпочтения"]
  BASIC --> STORY["Три вопроса или свободный текст<br/>можно пропускать и возвращаться"]
  STORY --> REVIEW["Проверка и сохранение истории<br/>20–6000 символов"]
  REVIEW --> PHOTO["Хотя бы одно фото<br/>предпросмотр и подтверждение"]
  PHOTO --> READY
  TOPICS -.->|"позже"| CHECK["Список недостающих шагов"]
  STORY -.->|"позже"| CHECK
  READY -->|"нет"| CHECK
  CHECK -->|"конкретный шаг"| BASIC
  CHECK --> STORY
  CHECK --> PHOTO
  READY -->|"да"| FEED["Знакомства<br/>свой город → остальные"]
  FEED --> REACT{"Like или Skip"}
  REACT -->|"Skip / Like без взаимности"| FEED
  REACT -->|"встречный Like"| MATCH["Это взаимно"]
  MATCH --> CHAT["Чат двух участников"]
  MATCH -->|"продолжить знакомства"| FEED
```
