# Проверки и воспроизведение

## Backend
`./mvnw test` / `.\mvnw.cmd test`:
- ApiIntegrationTest: 6 сценариев — основной путь, приватность и права; валидация/фильтрация; одновременные встречные like; пересмотр только собственных Skip с сохранением Like, совпадения и сообщений.
- DemoStartupTest: запуск всех 14 анкет с уникальными аватарами, заполненность, 12 интересов, не менее 10 сущностей, повторная инициализация.
- HttpStartupTest: реальный Tomcat, GET health, HTTP-вход demo5@nexus.local. Заглушки API не используются.
- LegacyMigrationTest: перенос интересов и возрастных предпочтений из старой схемы без потери аккаунта.
- LegacyInterestStartupTest: старт на существующей таблице interests с обязательной category, сохранение старой категории и повторная инициализация. CI также создаёт такую таблицу в PostgreSQL до первого старта backend и проверяет сохранённое значение после HTTP-сценария.
- PostgresIntegrationTest: основной API-сценарий на реальной PostgreSQL, включается TEST_POSTGRES_URL/USER/PASSWORD и профилем postgres.

В актуальном наборе 10 сценариев H2, включая настоящий HTTP-запуск и импорт старых данных. PostgreSQL проверяется отдельно; пропущенный PostgreSQL-тест не считается успешным прогоном на PostgreSQL.

## Frontend
`npm test`: 19 тестов — вход, профиль/интересы, чат, истечение сессии; JSON/Bearer для методов POST/PUT/PATCH, 204, HTML-ошибка прокси, недоступный backend, запоздалый 401 старого токена.
`npm run build`: TypeScript + production Vite.
`npm run smoke -- http://127.0.0.1:5173`: полный HTTP-сценарий через Vite, требует запущенных приложений; оставляет два тестовых аккаунта.

## Docker
`docker compose config --quiet` проверяет синтаксис и связи конфигурации. Это не заменяет реальную сборку и запуск.
CI фронтенда поднимает PostgreSQL + backend + nginx и выполняет smoke через 8088, затем поднимает отдельный backend с файловой H2 и выполняет тот же сценарий через настоящий Vite на 5173.

[Прогон 7 октября 2026, попытка 2](https://github.com/SMART-DATING/nexus-frontend/actions/runs/37678729625) прошёл: сборка контейнеров с серверными тестами, PostgreSQL/nginx, H2/Vite, 9 frontend-тестов и production-сборка. Проверены регистрация двух пользователей, профиль, интересы, предпочтения, рекомендации, приватность, встречные like, совпадение, сообщение, прочтение уведомлений и выход. Первая попытка остановилась при скачивании зависимости из Maven Central с HTTP 502; повторная прошла без изменения кода.

## Исправленные регрессии
- Повтор «Кофе» в Set.of приводил к завершению сервера при создании шестой анкеты.
- Профили H2/PostgreSQL теперь задают драйвер явно; Compose выбирает postgres.
- Справочник Interests включён в код; сущность Interest и связи реально сохраняются.
- Порты Vite фиксированы, proxy имеет changeOrigin; сетевые/не-JSON ошибки обрабатываются.
- Совпадения обновляются на открытом экране, старый 401 не уничтожает новую сессию.

Ручная приёмка: два окна, профиль, фильтр, встречный like, сообщения, уведомление, обновление страницы чата, выход; затем перезапуск с сохранением файловой БД. Визуальную проверку в браузере нельзя подменять компонентными тестами.
