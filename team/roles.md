# Команда и ответственность

Таблица закрепляет зоны координации. Фактический вклад в конкретное изменение отражают коммиты, задачи и review; назначенная роль сама по себе не является отчётом о выполненной работе.

| Тимошенко К. Е. | Backend, БД, инфраструктура; техническая координация | API, модель данных, смысловой подбор, доступ, интеграция, сборка и запуск |

## Совместные решения

Изменения правил подбора, доступа к данным и состава функций обсуждаются командой: аналитика фиксирует ожидаемое поведение, разработка уточняет ограничения, интерфейс делает результат понятным пользователю. Изменение API сопровождается обновлением клиента и документации.

У направления есть основной координатор, но задачи могут выполняться совместно. Автор изменения указывает проверки; проверяющий оценивает соответствие критериям и последствия для остальных частей. Команда не подменяет реальные ссылки на задачи вымышленной доской или отчётом о вкладе.
